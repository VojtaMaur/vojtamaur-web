## Oprava 0.3.4

pip wheel/install pracuje s nativním kontejnerovým /package-tmp/result. Pevný
host-owned driver pak přenáší souborové bajty do private wheels/.packages bez
shutil.copystat. Metadata chmod se použijí, pokud filesystem podporuje operaci;
EPERM/ENOTSUP se toleruje pouze pro mode update, nikoli pro chyby čtení/zápisu.
Konzolový script musí zůstat executable. Symlinky a cesty mimo cílový podstrom
jsou odmítnuty. Staré top-level položky aktualizované instalací se nahrazují;
částečné selhání má zůstat BLOCKED, ne být vydáváno za úspěch.

Online fetch stále vidí jen prázdný build staging. Offline install má readonly
wheelhouse a svou private workspace. Extra tmpfs /package-tmp je jen pro balíčky,
512 MiB, používá stávající cgroup paměťový limit; velké buildy mohou limit vyčerpat.
Normální experimenty nadále mají network none, read-only root, non-root uživatele
a původní noexec /tmp. Host secrets ani projekt nejsou připojeny online.

Reporter má samostatné read-only zadání, SDK observation tools a hostovou stopku
pro install/experiment/deposit. Toto je role capability, nikoli human approval.
Prototyper zachovává vlastní výběr a realizaci v mezích operator policy.
