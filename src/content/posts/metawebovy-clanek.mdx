## MANIFEST

Tento web je statický projekt zaměřený na dlouhodobé uchování obsahu.

Veškerý obsah je uložený v souborech, bez závislosti na databázích nebo externích systémech. Výsledný web se generuje jako statický výstup, který lze snadno kopírovat, archivovat a znovu sestavit.

Projekt je rozložený napříč více nezávislými systémy: repozitáři, archivními službami a statickými snapshoty. Tím se snižuje riziko ztráty dat.

Cílem je zajistit, aby bylo možné obsah rekonstruovat i v případě, že některé části původní infrastruktury přestanou existovat.

## VSTUPNÍ BODY

Tyto odkazy představují stejný projekt uložený v různých systémech a v různých podobách.

Zahrnují kanonický zdrojový repozitář, jeho kopie a kompletní statické snapshoty. Dohromady vytvářejí redundantní strukturu navrženou tak, aby projekt uchovala a umožnila jeho rekonstrukci i v případě, že některé části přestanou být dostupné.  

Projekt existuje také jako Python CLI balíček distribuovaný přes GitHub a PyPI, včetně vložených fallback snapshotů vybraných textových artefaktů.  

Digitální archivace tohoto webu tak využívá kromě vlastní domény také služby GitHub, GitLab, Codeberg, Neocities, Cloudflare, Netlify, Vercel, Firebase, Arweave, Software Heritage, Internet Archive, Webarchiv, Zenodo, Figshare, Permanent.org, Proton.me, PyPI, Perma.cc, archive.today, Ghost Archive, Arquivo.pt, Megalodon / Web Gyotaku a paste.rs.

## ZDROJOVÝ BALÍK K REKONSTRUKCI

Zdrojový balík webu vzniká automaticky při buildu. 

Uvnitř balíku je zdrojový kód tohoto webu, manifest assetů, kontrolní součty SHA-256 a Python skript bez externích závislostí. Neobsahuje velké assety z `public/images/`, `public/files/` a `public/demos/`, aby se velikost živého webu zbytečně nezdvojovala. Po rozbalení skript nejdřív zkusí assety zkopírovat lokálně z hotového buildu a teprve potom je stahuje z veřejných mirrorů.

Platí tedy, že zdrojový kód generuje build a build generuje zdrojový kód.  

Zdrojový balík je rekurzivně rekonstruovatelný: po stažení assetů a instalaci závislostí lze z něj znovu vygenerovat web i nový zdrojový balík.  

[Stáhnout rekonstruovatelný zdrojový balík webu (vojtamaur-web-source.zip)](/source/vojtamaur-web-source.zip)

## INTEGRITA A IDENTITA BUILDU

SHA-256 ověřuje, zda se soubory buildu nezměnily. OpenPGP podpis navíc umožňuje ověřit, že manifest kontrolních součtů podepsal autor tohoto webu.

[SHA256SUMS.txt](/SHA256SUMS.txt) — seznam SHA-256 kontrolních součtů souborů buildu  
[SHA256SUMS.txt.asc](/SHA256SUMS.txt.asc) — oddělený OpenPGP podpis souboru `SHA256SUMS.txt`  
[BUILD_SHA256.txt](/BUILD_SHA256.txt) — SHA-256 kontrolní součet souboru `SHA256SUMS.txt`  
[integrity.json](/integrity.json) — strojově čitelný informativní popis integrity buildu  
[SIGNING_STATUS.txt](/SIGNING_STATUS.txt) — informativní stav podepsání konkrétního buildu  
[vojta-maur-openpgp.asc](/keys/vojta-maur-openpgp.asc) — veřejný OpenPGP klíč pro ověření podpisu

<OpenPgpFingerprint label="Fingerprint hlavního OpenPGP klíče:" />

Ne každý deployment musí být podepsaný. Podepsaný build musí obsahovat soubor `SHA256SUMS.txt.asc` a jeho podpis se musí úspěšně ověřit. Samotné tvrzení v `integrity.json` nebo `SIGNING_STATUS.txt` není důkazem platného podpisu; tyto soubory jsou pouze informativní.

## TEXTOVÝ EXPORT VŠECH ČLÁNKŮ  

Plain-text export všech článků generovaný při buildu webu. Obsahuje textový obsah příspěvků v lineární podobě bez závislosti na CSS, JavaScriptu nebo konkrétní webové technologii. Slouží jako minimální archivní vrstva pro indexaci, offline čtení, fulltextové vyhledávání a dlouhodobou rekonstruovatelnost obsahu i v případě částečného rozpadu původní struktury webu. Textový export je vhodný i pro velké jazykové modely.  

[Zobrazit textový export všech článků (ALL_POSTS.txt)](/ALL_POSTS.txt)
